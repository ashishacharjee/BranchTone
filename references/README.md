# Reference image guide

## Primary authority

`branchtone-master-ui.png` is the latest approved BranchTone UI reference. It is the only authority for application layout, graph structure, brand colours, nav, inspector, validation treatment and timeline composition.

## Secondary references

- `linc-fast-contacts.jpg`: visual reference for small data counters and floating circular media/contact elements; do not reproduce the LINC content/layout.
- `linc-tablet-dashboard.jpg`: visual reference for rounded modular panels, spacing and gradient card finish; not a BranchTone layout reference.
- `linc-quick-notes.jpg`: secondary reference for restrained green gradient and dot-matrix numerals.
- `linc-daily-intake.jpg`: secondary reference for restrained burgundy gradient and dot-matrix numerals.
- `linc-handheld-dashboard.jpg`: secondary reference for card hierarchy and material finish only.

Do not copy their branding, text, photos, device renderings, product UI structure or full-screen composition. BranchTone retains its charcoal/emerald/burgundy visual identity.
